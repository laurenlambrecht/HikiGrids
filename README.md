# Hiki Grids

Hiki Grids is an interactive web application developed collaboratively as a product design and prototyping project.

This repository is a fork of the original project, developed with Samuel Bingham and Jamie Paik, through a partnership with Hiki Neurodivergent Dating. As per project instructions, we aimed to find a way to 'reimagine online dating' by replacing the left-right swiping mechanism with something that felt more human.

This prototype serves as a record of our work, and provides a look into the product's design, development, and functionality.
